# Upstream brand assets

These files were inherited from the Neovim website and are retained for
historical reference. They are outside Hugo's static files and templates, so
they are not published as Rustvim branding.

The Neovim logo is by [Jason Long](https://x.com/jasonlong), licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), as credited on the
original website.

Rustvim's current logo is `static/logos/rustvim-logo.png`.
