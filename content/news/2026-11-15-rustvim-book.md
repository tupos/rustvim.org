---

The [Rustvim Book](https://book.rustvim.org/) is now available online.

It follows the source code to explain what each component does, which data
it owns, and how Rust and C code interact.

The current chapters cover rendering concepts, the C `win_line`
implementation, and a walkthrough of the Rust modules. The book will grow
as more components are documented.

See the [roadmap](/roadmap/) for the work toward release **0.1.0**.
